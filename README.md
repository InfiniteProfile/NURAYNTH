# نورَينث · NŪRAYNTH
موقع ثابت (HTML/CSS/JS بلا مكتبات). عربي افتراضيًا وRTL، مع ترجمة إنجليزية اختيارية لكل بطاقة.

## النشر
ارفع الملفات الأربعة (`index.html`, `style.css`, `script.js`, `README.md`) إلى أي استضافة ثابتة (GitHub Pages، Netlify، Cloudflare Pages)، أو شغّل محليًا: `python3 -m http.server`. لا حاجة لخادم أو حساب. الخط (Noto) يُحمَّل من Google Fonts مع بدائل نظامية عند تعذّره.

## كيف يعمل
- **الهوية**: المعرّف نص عشري قانوني (إزالة الأصفار البادئة، قبول الأرقام الهندية). لا يُحوَّل أبدًا إلى Number/parseInt. الزيادة بالنص (`inc`).
- **التوليد**: يُشتق الملف من تجزئة (cyrb128 + sfc32) للمعرّف **كاملًا**؛ نفس المعرّف يعطي نفس الملف. الاسم الإنجليزي يتضمن المعرّف كاملًا فيبقى فريدًا. الملفات مولَّدة خوارزميًا وليست مستخدمين حقيقيين.
- **البحث المباشر**: الانتقال لمعرّف يبدأ التغذية منه دون توليد ما قبله. لا سقف للأرقام في الكود. اسم المستخدم التام يُحَل مباشرة؛ التطابق الجزئي يشمل الملفات المحمّلة فقط.
- **اللانهاية**: دفعات 300؛ تبدأ الدفعة التالية حين يبقى أقل من ~200 ملف أمام العارض (أي قرب الملف 100 من أول دفعة) ويزداد الهامش مع سرعة التمرير. المحرّك: scroll/rAF + IntersectionObserver + مراقب دوري + إعادة محاولة بتأخير. لا توليد أثناء الخمول.
- **الذاكرة**: افتراضي (DOM محصور بما حول الشاشة). عند تجاوز ~12000 ملف تُحذف الأقدم مع تعويض موضع التمرير.

## حدود صريحة
- بعد حذف الأقدم لا يمكن التمرير للخلف إلى ما قبل النافذة المحتفظ بها؛ استخدم البحث بالمعرّف للعودة.
- الأرقام الضخمة جدًا تحدّها ذاكرة المتصفح؛ لا يوجد سقف في التطبيق نفسه.
- الإنجليزية في البطاقات صياغات قالبية؛ لا تُنقل آيات أو أحاديث على البطاقات. الآية في صفحة «عن المشروع» بلا ترجمة.
